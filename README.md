# Credit Scoring — Предсказание дефолта по кредиту

Проект по построению модели кредитного скоринга, предсказывающей вероятность невозврата кредита (дефолта). Модель анализирует характеристики заёмщика и параметры кредита, чтобы помочь банку принимать решения о выдаче.

## Датасет

**Источник:** [Loan Approval Classification (Kaggle)]([https://www.kaggle.com/datasets](https://www.kaggle.com/datasets/taweilo/loan-approval-classification-data/data)) — 45 000 записей, 14 признаков.

**Целевая переменная:** `loan_status` (0 — кредит погашен, 1 — дефолт)


| Признак                   | Описание                                  |
| -------------------------------- | ------------------------------------------------- |
| `person_age`                     | Возраст заёмщика                   |
| `person_gender`                  | Пол                                            |
| `person_education`               | Уровень образования             |
| `person_income`                  | Годовой доход                         |
| `person_emp_exp`                 | Стаж работы (лет)                    |
| `person_home_ownership`          | Тип жилья (Own / Rent / Mortgage / Other) |
| `loan_amnt`                      | Сумма кредита                         |
| `loan_intent`                    | Цель кредита                           |
| `loan_int_rate`                  | Процентная ставка                 |
| `loan_percent_income`            | Доля кредита от дохода         |
| `cb_person_cred_hist_length`     | Длина кредитной истории      |
| `credit_score`                   | Кредитный скор                       |
| `previous_loan_defaults_on_file` | Наличие прошлых дефолтов    |

Баланс классов: **78% погашенных** / **22% дефолтов** — выраженный дисбаланс.

## Что сделано

### 1. Exploratory Data Analysis (EDA)

- Анализ распределений числовых и категориальных признаков
- Обнаружение и удаление выбросов (возраст > 100 лет, нереалистичный стаж работы) — удалено 52 строки из 45 000
- Корреляционный анализ — мультиколлинеарность не обнаружена
- Анализ категориальных признаков по уровню дефолта

### 2. Feature Engineering

Создано **9 новых признаков**, в том числе:

- `income_per_age` — доход на год жизни (показатель карьерного роста)
- `credit_utilization` — отношение суммы кредита к кредитному скору
- `employment_stability` — стаж / возраст
- `loan_to_income_abs` — абсолютное отношение кредита к доходу
- `debt_burden_category` — категория долговой нагрузки
- `high_debt_burden` — флаг высокой нагрузки (loan_percent_income > 0.4)

### 3. Предобработка

- **Кодирование:** binary mapping для пола и дефолтов, One-Hot Encoding для номинальных, Ordinal Encoding для образования
- **Масштабирование:** StandardScaler для числовых признаков
- **Разбивка:** Train 70% / Validation 15% / Test 15% со стратификацией

### 4. Моделирование

Протестированы три модели с подбором гиперпараметров и оптимального порога классификации:


| Модель        |  Recall  | Precision |    F1    |  ROC-AUC  | Threshold |
| ------------------- | :------: | :-------: | :------: | :-------: | :-------: |
| Logistic Regression |   0.90   |   0.62   |   0.73   |   0.951   |   0.50   |
| Random Forest       |   0.97   |   0.58   |   0.72   |   0.972   |   0.25   |
| **XGBoost** ✅      | **0.94** | **0.69** | **0.80** | **0.979** | **0.30** |

## Результат
